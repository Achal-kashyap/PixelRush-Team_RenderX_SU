# 🚀 PixelRush - Team RenderX SU

Welcome to the **PixelRush** project repository created by **Team RenderX SU** for the [CodingGita Hackathon](https://github.com/CodingGita-Hackathon-Commitee). This project is a web application designed for event management, ticket/pass booking, and schedule tracking.
📌 Project Overview
PixelRush provides a seamless user experience to explore events (like Thanganat), view event calendars, manage user authentication, and access digital passes.

🛠️ Tech Stack
HTML5: For structuring the web pages.

CSS3: For styling and layout design.

📂 Repository Structure
Plaintext
├── images/                         # Static images and visual assets
├── Event.html                      # Events overview page
├── Thanganat.html                  # Specific details page for 'Thanganat' event
├── calendar.html                   # Event schedule and calendar view
├── index.html                      # Main landing page
├── login.html                      # User authentication/login page
├── my-pass.html                    # User's saved passes page
├── navbar.html                     # Navigation bar component
├── pass.html                       # Pass generation/booking page
├── event.css                       # Stylesheet for event pages
├── my-pass.css                     # Stylesheet for user passes and homepage
├── style.css                       # Core global stylesheet
└── thanganatandcalender.css        # Combined stylesheet for Thanganat & Calendar pages
🌟 Key Features
User Authentication: Secure login interface (login.html).

Event Discovery: Detailed view of upcoming events (Event.html, Thanganat.html).

Event Calendar: Interactive schedule tracking (calendar.html).

Pass Management: Easily view and access event passes (pass.html, my-pass.html).
